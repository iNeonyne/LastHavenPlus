# Agent contribution policy

LastHavenPlus is operated through authorized agent contributions. There is no separate human contributor workflow or alternate set of contribution rules.

Before changing the repository, every agent must read [AGENTS.md](AGENTS.md) in full and follow the startup sequence in [AGENT_PROTOCOL.md](AGENT_PROTOCOL.md). Work requires an explicit GitHub issue assignment from Chaty; the issue defines scope and acceptance criteria.

AGENTS.md is the only authoritative source for roles, permissions, implementation workflow, PR integration, testing, and engineering constraints. Do not copy those rules into this file. Current assignments, task scope, blockers, and progress are recorded only in GitHub Issues and pull requests. AGENT_WORK.md is a historical archive; STATUS.md and ISSUES.md are not live task sources.
