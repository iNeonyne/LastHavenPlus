# Security Policy

## Supported versions

Security fixes are made against the actively maintained `beta` branch. Stable-release fixes may be provided through a later approved release.

## Reporting a vulnerability

**Do not report security vulnerabilities in public GitHub issues, discussions, or pull requests.**

Use GitHub's private vulnerability reporting feature for this repository (Security → Advisories → Report a vulnerability) when it is enabled. If private reporting is unavailable, contact the repository maintainer privately through the contact method listed on the maintainer's GitHub profile. Include steps to reproduce, affected versions or commits, and the potential impact. Do not include real user credentials, session cookies, or other secrets in a report.

Please allow the maintainer reasonable time to investigate and coordinate a fix before public disclosure. No fixed response or resolution time is guaranteed.

## Scope

Reports may cover the LastHavenPlus Android launcher, its updater, repository automation, build and release workflows, and project-controlled infrastructure.

The LastHaven game service and website, Mozilla GeckoView, Android, and other third-party dependencies are maintained by their respective owners. Report vulnerabilities in those components to their upstream security teams as well; explain any demonstrated impact specific to LastHavenPlus when reporting here.
